# Software Testing Guide

This project was created for Futuregames Frontend Development - Assignment 1.

The purpose of the assignment is to create a responsive multi-page website using HTML and CSS.

## Website Overview

Software Testing Guide is a simple educational website introducing basic software testing concepts and testing types.

## Pages

### Home

The main page introduces the Software Testing Guide and provides a short overview of software testing.

### Testing Types

This page introduces different types of software testing, including:

- Manual Testing
- Automation Testing
- API Testing
- Regression Testing

### Contact

The contact page contains a form where the user can enter:

- Email address
- Message

Both fields are required before the form can be submitted.

## Navigation

The navigation menu is available on every page.

Use:

- **Home** to return to the main page
- **Testing Types** to view software testing information
- **Contact** to open the contact form

## How to Run the Website

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation menu to move between pages.
